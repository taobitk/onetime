NHÓM 1 五段 (Godan)
➔ -masu: đổi hàng [u] sang [i] + ます
Đuôi [-u] ➔ -masu ➔ -te Ví dụ minh họa
う / つ / る Trước る là [a/u/o] (toru, wakaru) い / ち / ります 〜って かう➔かって / とる➔とって
む / ぶ / ぬ み / び / にます 〜んで のむ➔のんで / あそぶ➔あそんで
く きます 〜いて かく➔かいて / きく➔きいて
ぐ ぎます 〜いで およぐ➔およいで
す します 〜して はなす➔はなして / かす➔かして
NHÓM 2 一段 (Ichidan)
[i/e] + る

Trước る là âm hàng [i] hoặc [e] (taberu, miru). Bỏ る, ghép thẳng ます/て

たべる (taberu) ➔ たべます / たべて
みる (miru) ➔ みます / みて
おきる (okiru) ➔ おきます / おきて
NHÓM 3 不規則 (Bất quy tắc)
2 từ gốc

Quy tắc: Biến đổi gốc từ (học thuộc lòng)

する (suru) ➔ します / して
くる (kuru) ➔ きます / きて
べんきょうする ➔ 〜します / 〜して

Nhóm 1: Trước る là hàng [a] / [u] / [o]
Ví dụ: to-ru, waka-ru ➔ ru biến thành ります / って
いく (iku: đi) Đuôi く nhưng chia ngoại lệ
-masu: いきます
-te: いって (không phải いいて)
Đuôi -iru / -eru nhưng là Nhóm 1
• かえる (kaeru - về) ➔ かえります / かえって
• はいる (hairu - vào) ➔ はいります / はいって
• しる (shiru - biết) ➔ しります / しって
• はしる (hashiru - chạy) ➔ はしります / はしって
• きる (kiru - cắt) ➔ きります / きって
