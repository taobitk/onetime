Tổng Hợp 4 Điểm Ngữ Pháp Trọng Tâm Bài 12

Thể quá khứ của Tính từ / Danh từ & Toàn bộ các mẫu câu So sánh (Hơn, Lựa chọn, Nhất).

1. Thể Quá Khứ của Tính Từ và Danh Từ

● Tính từ đuôi い
  • [Khẳng định]: Bỏ い + かったです
    Ví dụ: きのうは 忙しかったです。(Hôm qua đã bận.)
    Đặc biệt: いい → よかったです
  • [Phủ định]: Bỏ い + くなかったです
    Ví dụ: きのうは 暑くなかったです。(Hôm qua không nóng.)
● Tính từ đuôi な & Danh từ
  • [Khẳng định]: Bỏ な / N + でした
    Ví dụ: 試験は 簡単でした。(Kỳ thi đã rất dễ.)
    Ví dụ: きのうは 雨でした。(Hôm qua trời đã mưa.)
  • [Phủ định]: Bỏ な / N + じゃありませんでした
    Ví dụ: 暇じゃありませんでした。(Đã không rảnh.)

2. Cấu trúc So sánh hơn (N1 hơn N2)

N1 は N2 より [Tính từ] です

• より mang nghĩa là "so với". Đối tượng đứng trước は là đối tượng chiếm ưu thế về tính chất.
• Muốn nhấn mạnh "hơn hẳn, nhiều hơn" thì thêm ずっと trước tính từ.

🚗 車は 自転車より 速いです。(Ô tô nhanh hơn xe đạp.)
🏙️ 東京は 大阪より ずっと 賑やかです。(Tokyo nhộn nhịp hơn hẳn Osaka.)

3. So sánh giữa 2 đối tượng (Mẫu câu lựa chọn)

Hỏi: N1 と N2 と どちらが [Tính từ] ですか。
Đáp: N の ほうが [Tính từ] です。 / どちらも [Tính từ] です。
A: すき焼きと 刺身と どちらが 好きですか。
B: すき焼きの ほうが 好きです。(Tôi thích Sukiyaki hơn.)
A: 春と 秋と どちらが 好きですか。
B: どちらも 好きです。(Cả hai tôi đều thích.)

4. Cấu trúc So sánh nhất (Trong một phạm vi)

Hỏi: [Phạm vi] で [Từ để hỏi] が いちばん [Tính từ] ですか。
Đáp: [N] が いちばん [Tính từ] です。

Từ để hỏi thay đổi theo phạm vi: Thời gian dùng いつ, nơi chốn dùng どこ, người dùng だれ, đồ vật/món ăn dùng なに (何).

🌍 一年で いつが いちばん 寒いですか。 → 冬が いちばん 寒いです。
🍣 日本料理で 何が いちばん おいしいですか。 → 寿司が いちばん おいしいです。
🗾 日本で どこが いちばん 広いですか。 → 北海道が いちばん 広いです。
👨‍👩‍👦 家族で だれが いちばん 背が高いですか。 → 兄が いちばん 高いです。
📖

Sổ Tay Ngữ Pháp Nhanh - Bài 12

1. Quá khứ Tính từ đuôi い
• Khẳng định: Tính từ い (bỏ い) + かったです
• Phủ định: Tính từ い (bỏ い) + くなかったです
2. Quá khứ Tính từ đuôi な & Danh từ
• Khẳng định: Tính từ な (bỏ な) / Danh từ + でした
• Phủ định: Tính từ な / Danh từ + じゃありませんでした
3. So sánh hơn & So sánh chọn 2
• Hơn: N1 は N2 より [Tính từ] です (N1 hơn N2)
• Lựa chọn: N1 と N2 と どちらが [Tính từ] ですか
• Trả lời: N の ほうが [Tính từ] です (hoặc どちらも ... です)
4. So sánh nhất trong phạm vi
• [Phạm vi] で [いつ/どこ/だれ/なに] が いちばん [Tính từ] ですか
• Trả lời: [N] が いちばん [Tính từ] です
